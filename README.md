## Chat App - Socket.IO

A real-time chat application built with Node.js and Socket.IO, demonstrating event-driven communication between connected clients.

### Overview

This project implements a browser-based chat application using Socket.IO for real-time, bidirectional communication between clients and the Node.js server.

The application separates the frontend into HTML, CSS, and JavaScript files, while the backend handles server-side communication and maintains utility modules for managing messages and connected users.

### Topics Covered

- Real-time, bidirectional communication using Socket.IO
- Client-server event-based communication
- Node.js server implementation
- Managing connected users
- Message handling and communication utilities
- Frontend integration with Socket.IO


### Getting Started

**Prerequisites:** Node.js and npm.

1. Clone the repository:

   ```bash
   git clone https://github.com/naba93980/chat-app-socket.io.git
   ```

2. Navigate to the project directory:

   ```bash
   cd chat-app-socket.io
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the application:

   ```bash
   npm start
   ```


5. Open the application in your browser using the server URL (`http://localhost:3000`, depending on the server configuration).

### Purpose

A hands-on project for understanding real-time web application development using Socket.IO and Node.js, with a focus on client-server communication, message handling, and connected-user management.
